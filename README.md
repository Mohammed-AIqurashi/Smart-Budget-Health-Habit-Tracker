# 💰 Smart Budget & Health Habit Tracker

> 🌐 **رابط تجربة الموقع المباشر (Live Demo):**  
> [https://smart-budget-frontend-pe9m.onrender.com](https://smart-budget-frontend-pe9m.onrender.com)

منصة متكاملة وحديثة لإدارة المصروفات والميزانية الشخصية، وتتبع العادات الصحية والغذائية اليومية في مكان واحد، مع إمكانية محاكاة تقليل النفقات وتوقع التوفير المالي والسعرات على المدى الطويل.

---

## 🌟 أبرز مميزات المشروع (Key Features)

### 1. لوحة تحكم ذكية وشاملة (Dashboard)
- **مؤشر الميزانية المتبقية**: متابعة فورية للميزانية مع مراعاة الدخل والمصروفات.
- **إحصائيات ذكية**: متوسط الإنفاق اليومي، الإنفاق المتوقع بنهاية الشهر، ومتوسط السعرات اليومية.
- **رسوم بيانية تفاعلية**: رسم بياني دائري لتوزيع المصروفات حسب الفئات، ورسم بياني يربط بين المصروفات اليومية ومعدل السعرات.
- **سجل المعاملات الأخيرة**: عرض مباشر لأحدث العمليات المالية مع إمكانية التعديل والحذف.

### 2. التسجيل السريع المزدوج (Quick Log)
- تسجيل المعاملات المالية (دخل / مصروف) والعادات الصحية (سعرات، ماء، خطوات، نوم، وماكروز) في نفس النافذة وبنقرة واحدة.

### 3. محاكي التوفير المالي (Smart Budget Simulator)
- التحكم بنسبة تقليل المصروفات في فئات محددة عبر شرائح تحكم تفاعلية (Sliders).
- حساب التوفير المالي والسعرات المتوقع لـ 3، 6، و 12 شهراً بشكل فوري.

### 4. إدارة المعاملات المالية (Transactions)
- فلترة متقدمة حسب نوع المعاملة (دخل/مصروف)، الفئة، البحث النصي، والفترة الزمنية.
- تقسيم الصفحات (Pagination) وتصدير كافة البيانات بملف **CSV**.

### 5. متابعة العادات والصحة (Health & Habit Tracker)
- تتبع دقيق لـ: **السعرات، شرب الماء، الخطوات، ساعات النوم، والماكروز (البروتين، الكارب، الدهون)**.
- **فلترة مرنة للإحصائيات**: حساب الملخص اليومي بحسب: **اليوم الحالي**، **جميع الأيام**، أو **فترة مخصصة (من تاريخ إلى تاريخ)** مع أشرطة تقدم نحو أهدافك اليومية.

### 6. التخصيص والإعدادات (Settings)
- ضبط الميزانية الشهرية وأهداف الصحة والماكروز اليومية (سعرات، بروتين، كارب، دهون، ماء، خطوات، ونوم).
- دعم كامل للغتين: **العربية** و **الإنجليزية** مع دعم RTL.
- التبديل السلس بين **الوضع الليلي (Dark Mode)** و **الوضع الفاتح (Light Mode)**.
- إضافة وإدارة فئات مخصصة للمصروفات والدخل.

---

## 🔧 التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 18, Vite, Tailwind CSS, Recharts, Lucide Icons, Axios, React Router.
- **Backend**: Node.js, Express.js, Prisma ORM, JWT Authentication, Bcrypt.js.
- **Database**: Cloud Neon PostgreSQL (Serverless).
- **Hosting**: Render Cloud Platform.
